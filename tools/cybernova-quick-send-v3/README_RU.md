# Cybernova Quick Send v3.0.1

Локальное Chrome Extension для отправки выделенного текста с любого сайта или текста из системного буфера в открытый авторизованный диалог ChatGPT.

## Использование

- Любой обычный сайт: выделить текст → правая кнопка → «Cybernova → отправить выделенное в ChatGPT».
- CMD / PowerShell / Windows Terminal: выделить и скопировать вывод штатным способом; перейти в ChatGPT; нажать правой кнопкой внутри поля ввода → «Cybernova → вставить буфер и отправить».
- Горячая клавиша Chrome: Alt+Shift+Y отправляет буфер в последний активный диалог ChatGPT.

## Архитектура

Manifest V3, contextMenus, service worker и content.js на страницах ChatGPT.
Буфер читает content.js внутри активной и сфокусированной вкладки ChatGPT через navigator.clipboard.readText() с разрешением clipboardRead.

Offscreen document удалён: Chrome offscreen documents нельзя фокусировать, а Clipboard API требует подходящего сфокусированного контекста. Это было причиной NotAllowedError в v3.0.0.

Нет Python Bridge, WebSocket, локального TCP-порта, Vast, SSH-туннеля, внешнего API или API-ключа.

## Установка / обновление

1. Распаковать комплект в постоянную папку.
2. Открыть chrome://extensions.
3. Нажать «Обновить» у Cybernova Quick Send либо удалить старую версию расширения и загрузить новую папку extension.
4. Убедиться, что разрешение clipboardRead выдано.
5. Обновить вкладку ChatGPT.

## Разрешения и приватность

clipboardRead позволяет расширению читать системный буфер только при явном выборе пользователем команды «вставить буфер и отправить» или горячей клавиши. Скрипт не опрашивает буфер в фоне и не сохраняет историю буфера. Host permissions ограничены доменами ChatGPT; выделенный текст на других сайтах передаётся Chrome через событие контекстного меню.

Старую Cybernova_Background_NumpadEnter_v2_1_FIXED пока не удалять до проверки новой версии. Старый bridge.py не запускать. Порты 18883/18884 Quick Send не использует.
