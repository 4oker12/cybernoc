# Cybernova Quick Send v3.0.2

Локальное Chrome Extension для отправки выделенного текста в ChatGPT или в локальную панель Cybernova.

## Использование

- Любой обычный сайт: выделить текст → правая кнопка → «Cybernova → отправить выделенное в ChatGPT».
- CMD / PowerShell / Windows Terminal: скопировать вывод; перейти в ChatGPT; нажать правой кнопкой внутри поля ввода → «Cybernova → вставить буфер и отправить».
- Горячая клавиша Chrome: Alt+Shift+Y отправляет буфер в последний активный диалог ChatGPT.
- Локальная панель: на странице 127.0.0.1 с портом 18785–18805 выделить текст → правая кнопка → «Cybernova → отправить выделенное в локальную панель».

## Локальные разрешения

Добавлено host permission `http://127.0.0.1/*`. Синтаксис Chrome host permissions не поддерживает ограничение порта в match pattern, поэтому разрешение браузера технически распространяется на все HTTP-порты этого IP.

Чтобы не запускать скрипт на всех этих портах, service worker проверяет URL до внедрения:
- только схема HTTP;
- только IP 127.0.0.1;
- только порты 18785–18805 включительно.

Content script внедряется динамически при загрузке вкладки только в разрешённом диапазоне. В самом content script есть дополнительная проверка диапазона. Локальная команда контекстного меню также проверяет порт перед отправкой.

## Архитектура и приватность

Manifest V3, contextMenus, service worker и content.js.
Буфер читается только после явного действия пользователя; фонового опроса и истории буфера нет.
Нет Python Bridge, WebSocket, локального TCP-порта для Quick Send, Vast, SSH-туннеля, внешнего API или API-ключа.

## Обновление

1. Открыть `chrome://extensions`.
2. Нажать «Обновить» у Cybernova Quick Send либо загрузить распакованную папку новой версии.
3. Обновить вкладки ChatGPT и локальной панели.
4. Проверить работу меню на `http://127.0.0.1:18795/`.

Старую Cybernova_Background_NumpadEnter_v2_1_FIXED пока не удалять до проверки новой версии. Порты 18883/18884 Quick Send не использует.
