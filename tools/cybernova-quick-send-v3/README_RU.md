# Cybernova Quick Send v3

Чистое локальное Chrome Extension для отправки текста в открытый авторизованный диалог ChatGPT.

## Использование

- Любой обычный сайт: выделить текст → правая кнопка → «Cybernova → отправить выделенное в ChatGPT».
- CMD / PowerShell / Windows Terminal: выделить и скопировать вывод штатным способом; перейти в ChatGPT; нажать правой кнопкой внутри поля ввода → «Cybernova → вставить буфер и отправить».
- Горячая клавиша Chrome: Alt+Shift+Y отправляет буфер в последний активный диалог ChatGPT.

## Архитектура

Manifest V3, contextMenus, service worker, content.js и offscreen document для Clipboard API.
Нет Python Bridge, WebSocket, локального TCP-порта, Vast, SSH-туннеля, внешнего API или API-ключа.

## Установка

1. Распаковать комплект в постоянную папку.
2. Открыть chrome://extensions.
3. Включить «Режим разработчика».
4. Нажать «Загрузить распакованное расширение».
5. Выбрать папку extension.
6. Обновить вкладку ChatGPT.

## Разрешения

clipboardRead нужен для чтения буфера только после явного выбора команды «вставить буфер и отправить» или горячей клавиши. Chrome показывает соответствующее предупреждение. Скрипт не мониторит буфер и не собирает содержимое страниц в фоне. Host permissions ограничены доменами ChatGPT; пункт отправки выделенного текста добавляется в контекстное меню Chrome на любых сайтах.

Старую Cybernova_Background_NumpadEnter_v2_1_FIXED пока не удалять до проверки новой версии. Старый bridge.py не запускать. Порты 18883/18884 Quick Send не использует.
